# CSV frontend presentations

The 151 imported CSV pages use the existing version-2 content schema directly. URL and section layout mappings live in `src/templates/presentations.json`, rebuilt with `npm run design:presentations`. This file contains presentation metadata only, never prompts, evidence or draft copy. The original HTML prototypes and legacy renderer remain available.

AI Process Automation establishes the first service layout: violet hero with SVG workflow artwork, grouped H3 capabilities, comparison panels and tables, connected process cards, technology tiles, FAQ accordions and closing enquiry CTA. The inventory uses 14 layout families with section variants chosen from its required heading structure. H3 sections remain nested under their preceding H2. Optional arrays render only when populated.

Admin Preview and public pages share `StructuredPage`. Preview uses authenticated revision data, maps links to other private previews, and disables enquiry storage. Production uses only the published revision, filters links against published paths, strips editorial notes/claims, and generates FAQ structured data from the visible FAQ pairs. Service CTAs preserve their CSV destination and carry the service title to the Contact form.

Admin receives a per-page `designReady` value. Known registered version-2 pages have a responsive renderer; unknown pages retain the design gate. This is separate from content completeness, approved evidence and publication. No draft was regenerated or published as part of presentation work. The presentation registry does not approve company capabilities, projects, prices or local office claims.

Checks: `npm test` verifies all 151 heading maps, nesting, readiness, private field filtering and visible structured data. `node --env-file-if-exists=.env tests/presentation-browser.cjs` verifies real private previews at desktop/mobile widths for each family, captures screenshots under `test-results/presentations`, checks capsule keyboard navigation, FAQs, contextual contact fields and preview-only form submission. This test does not publish drafts or save enquiries.
