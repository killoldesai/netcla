How we work

From brief to release, with agreed review milestones.

You know what you get at each stage before it starts, and you review it before the next one begins.

  1. Discovery

    Requirements, users, existing systems and constraints. We agree the initial scope and the questions that need further investigation.

    You receive

    • Scope summary
    • Open questions
    • Initial estimate

  2. Design and architecture

    User flows, interfaces, data structures and API requirements, reviewed with you before development begins.

    You receive

    • User flows
    • Interface designs
    • Architecture notes

  3. Development and review

    We work through agreed priorities with review milestones, an update cadence and acceptance criteria.

    You receive

    • Staging builds
    • Progress reviews
    • Test results

  4. Deploy and support

    Production release, handover and the ongoing support your application needs, agreed in the project scope.

    You receive

    • Production release
    • Documentation
    • Access handover
