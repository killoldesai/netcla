What we do

Custom software

Web applications, SaaS platforms, ERP and CRM systems and APIs, built on React, Node.js, Python and .NET. We plan the build around your users, workflows and the systems it has to connect to.

  • SaaS development
  • Enterprise software
  • API development

AI and automation

LLM integrations, chatbots grounded in your own content, document processing and machine learning models. We start with one specific task, check the data you have and decide where a person reviews the output.

  • Generative AI
  • AI chatbots
  • AI automation

Cloud and DevOps

AWS, Azure and Google Cloud architecture, migration, CI/CD pipelines and Infrastructure as Code with Terraform and Kubernetes. Built around the application you need to run and the team that will operate it.

  • Cloud migration
  • DevOps and CI/CD
  • AWS

Mobile apps

Native iOS and Android apps, plus cross-platform builds in Flutter and React Native. We choose the approach around your users, device features, release plan and maintenance budget.

  • iOS apps
  • Android apps
  • Cross-platform
