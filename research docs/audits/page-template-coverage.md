## Meaning and limits

A specification mapping enables the new pipeline; it does not migrate existing revisions. V3 adoption requires a generated or edited V3 draft and manual publication. Public routing selects the published revision, not the latest generated result. Missing mappings fall back to legacy generation. Some legacy hubs/homepage have custom modern rendering, so legacy content does not always mean old-looking design. All non-home V3 pages now inherit the common visual theme; page-family compositions still require representative visual review. CSV image flags determine whether image tasks exist. No-image specifications are intentional, not asset failures. Blank evidence fields may be intentional.

Checks include database identity, current source/import parity, exact draft section fields, approved blueprint components, designated hero references and persistent asset files. This is a code/database audit, not browser visual approval or a live external-provider test. Existing jobs do not guarantee future provider availability.
